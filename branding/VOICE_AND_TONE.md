# Communication Principles

Every message shown to the user should be:

* Clear
* Friendly
* Professional
* Respectful
* Concise

---

# Writing Style

Use simple language.

Avoid technical jargon.

Avoid unnecessary punctuation.

Prefer direct and positive wording.

---

# Error Messages

Explain:

* What happened.
* Why it happened (when appropriate).
* What the user can do next.

Example:

"Unable to save the document. Please check that enough storage space is available."

---

# Success Messages

Keep them brief.

Examples:

"PDF created successfully."

"Document saved."

"Pages merged."

---

# Empty States

Empty states should encourage users without sounding promotional.

Example:

"No documents yet.

Create your first PDF by tapping the Scan button."

---

# Notifications

Only notify users when the information is useful.

Avoid interrupting users unnecessarily.

---

# Brand Personality

DocWizer speaks like an experienced professional who enjoys helping people.

Confident.

Calm.

Respectful.

Never dramatic.

Never overly casual.
